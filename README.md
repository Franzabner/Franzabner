## Proof Stack

All public claims should route through [`franzabner-proof-stack`](https://github.com/Franzabner/franzabner-proof-stack).

The proof stack exists to map each public claim to:

- repository or artifact;
- approved status label;
- public/private/sealed boundary;
- validation method;
- evidence state;
- human review state;
- next review action.

A claim is not public proof just because it appears in a README. It must have status, boundary, validation, and review context.
