## Engineering Approach

- Start with the physical and operational reality.
- Make interfaces, ownership, and failure boundaries explicit.
- Separate prototypes, evidence, validation, and release claims.
- Keep private company source in Forgejo and publish only reviewed,
  public-safe work here.
